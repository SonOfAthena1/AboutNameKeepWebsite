Trouble Shooting Guide

The date shown beside a person is wrong—or I do not want to see it

The date is the date that person was added to NameKeep. It is not their birthday, age, or a date taken from their description.

To hide these dates, open Settings and turn off Show date.

I cannot find someone I saved

Use the search bar at the top of the main screen. Search looks through:

  • A person's name
  • Their description
  • Their label name

Also check the No Label section. People without a label appear there rather than under one of your named labels. If you still can't find them, check the Trash under Settings at the top right

I added a person without a name

NameKeep allows you to save a person without entering a name, so you can capture what you remember in the moment. It gives the person a temporary placeholder name. You can tap that person later and replace it with their real name.

I accidentally deleted someone

Deleting a person first moves them to Trash. Go to Settings → Trash, then choose Restore to put them back in your list.

Choosing Delete Forever for a person, or Empty Trash, permanently removes those people and cannot be undone.

I want to delete a label, but keep the people in it

When you delete a label, NameKeep lets you choose what happens to the people assigned to it:

  • Move them to another label
  • Move them to No Label
  • Move them to Trash

Choose a destination label if you want to keep everyone organized without re-entering their information.

My list is in an unexpected order

In Settings → Sorting, you can choose how labels and people are ordered:

  • Date, newest first
  • Date, oldest first
  • Alphabetical

People are sorted within each label section.

Importing people from a CSV file

Importing is the quickest way to bring an existing list into NameKeep. Go to Settings → Import people, review the guide, then choose a CSV file.

A CSV is a plain-text spreadsheet file. You can create one in Excel, Google Sheets, Numbers, or another spreadsheet app, then export or download it as a .csv file.

Required format

Your first row must include a column named name.

The complete supported format is:

name,description,label,label_color

Only name is required. The other columns are optional.

Example 1: A simple import

  1. name,description,label,label_color
  2. Maya Chen,Frontend developer on the mobile team,Work,green
  3. Jordan Lee,"Met at the quarterly planning meeting",Work,green
  4. Sarah,"Sits near the front; works at Starbucks",Classmates,blue
  5. Alex,"Study group; likes climbing",Friends,violet

This creates the labels Work, Classmates, and Friends, then adds the people beneath them.

Example 2: Labels, notes, and people without labels

  1. name,description,label,label_color
  2. Priya Shah,"Neighbor in apartment 4B",Neighbors,teal
  3. Marcus Hill,"Met at the conference",Networking,orange
  4. Elena Ruiz,"Friend of Jamie",,
  5. Noah Kim,,, 

Priya and Marcus receive labels. Elena and Noah are imported without a label and appear in the No Label section.

CSV rules and limits

  • The file name must end in .csv.
  • The file must be 2 MB or smaller.
  • A file can contain up to 5,000 people.
  • Names can be up to 30 characters.
  • Descriptions can be up to 100 characters.
  • Label names can be up to 30 characters.
  • description, label, and label_color may be left blank.
  • Valid label colors are: green, blue, violet, pink, red, orange, amber, teal, and gray.
  • A label_color must only be provided when that row has a label.
  • If a new label has no label_color, NameKeep uses your current default label color.
  • If a cell contains a comma, wrap its value in double quotes.

For example, this is correct:

name,description,label,label_color

Maya Chen,"Met at a cafe, works in design",Friends,pink

Without the quotation marks, the comma would split the description into separate columns.

What happens when you import

Before saving anything, NameKeep shows a summary of the people and new labels it found. You can cancel at that point if something does not look right.

NameKeep will:

  • Reuse existing labels with the same name.
  • Create new labels as needed.
  • Skip exact duplicate people instead of adding them again.
  • Skip invalid rows and identify their line numbers in the import review.

A duplicate means the person has the same name, description, and label as someone already in NameKeep—or as an earlier row in the same import.

Common import problems

“The CSV must contain a ‘name’ column.”
Add a header row at the top of your file. It must include name, for example:

name,description,label,label_color

“The selected CSV file is empty.”
Make sure the file contains both a header row and at least one person.

“The selected file is not valid CSV.”
Check for unmatched quotation marks or broken columns. If a value contains a comma, put the entire value in double quotes.

A row was skipped.
Check that it has a name, stays within the character limits, and uses one of the supported label colors. Rows with a color but no label are also skipped.

“Label … has conflicting colors in the CSV.”
Use one color for each new label. For example, do not use both green and blue for rows labeled Work in the same import.

Tip: export first

If you are unsure about the format, use Settings → Export people to create a CSV from your current NameKeep data. That exported file is a valid template you can edit and import again later.

Exporting people

Choose Settings → Export people to save or share a CSV copy of your current people and labels.

Exports include:

name,description,label,label_color

Exporting is useful for backups, editing a larger list in a spreadsheet, or moving your list to another device or app.

Memory reminders

Memory reminders are optional notifications that quiz you on people you add from that point onward. In Settings → Memory reminders, choose one or more reminder times:

  • 1 day later
  • 3 days later
  • 1 week later
  • 2 weeks later

NameKeep needs notification permission from your device. If reminders are not arriving, check that notifications are allowed for NameKeep in your device settings.

Display and appearance

In Settings, you can also:

  • Use your system appearance, light mode, or dark mode.
  • Choose a default label color.
  • Choose a default label for newly added people.
  • Show or hide the date each person was added.
  • Turn on Condensed view to fit more people on screen.
