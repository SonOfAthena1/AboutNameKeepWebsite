Release Notes

What’s new in 1.1.2

  • Any system navigation should no longer hide the "add" button (+).

What’s new in 1.1.1

  • Improved scrolling performance for large people lists.
  • Prevented overlapping CSV imports for more reliable importing.
  • General stability improvements.

What’s new in 1.1.0

  • Create labels while adding a new person.
  • Reminder notifications now include label and description details.
  • Android Back now returns from the label picker to the New Person form.
  • Person and label names can now be up to 35 characters, including in CSV imports.
  • Clearer error messages and recovery options help when a screen or the database fails to start.

What’s new in 1.0.0

  • Initial closed-testing release of NameKeep. This build is being tested for functionality, usability, and stability.
